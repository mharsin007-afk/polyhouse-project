\# Capstone Reflection



This capstone project provided hands-on experience in building an end-to-end machine learning system for agritech forecasting. I learned how to ingest, clean, analyse, and model environmental sensor data while applying best practices to avoid data leakage through chronological validation.



The project strengthened my understanding of model evaluation metrics, particularly Mean Absolute Error (MAE), and demonstrated the importance of monitoring deployed models for data drift and performance degradation.



My three most valuable skills gained during this project were building reproducible data pipelines, deploying machine learning applications with Streamlit, and implementing monitoring through structured prediction logging.



Moving forward, I want to deepen my knowledge of advanced feature engineering and MLOps practices, including automated retraining, model versioning, and continuous deployment workflows.
